# Audio Assets

Place the background music file here:

- **`calm-bg.mp3`** — Calm background music that plays during gameplay.

## Sourcing the file

Use any royalty-free calm/ambient track. Recommended sources:

- [Pixabay Music](https://pixabay.com/music/) — search "calm" or "ambient"
- [Free Music Archive](https://freemusicarchive.org/) — filter by CC0 licence
- [OpenGameArt](https://opengameart.org/) — search "calm background loop"

Download your chosen track, rename it to `calm-bg.mp3`, and place it in this
directory. The game will play it automatically when a round starts and stop it
when the round ends. If the file is absent the game continues to work normally
(the browser logs a warning but no error is thrown).
